# Especificaciones para generación con IA

Se conservan seis prompts porque corresponden a las seis tareas de generación solicitadas, aunque el agente v2 separa formalmente más componentes de arquitectura.

1. `01_database.md` - base de datos.
2. `02_business_logic.md` - lógica de negocio del backend.
3. `03_api_rest.md` - componente `communication` REST.
4. `04_android_fake.md` - implementación Android de `frontend_business_logic`.
5. `05_web_fake.md` - implementación web de `frontend_business_logic`.
6. `06_web_ux.md` - componente `gui` web.

Todos parten del diseño previo y prohíben rediseñar silenciosamente el sistema.
